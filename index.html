Как сдавать решения

  1. Открой задачу и прочитай условие из архива олимпиады.
  2. Напиши код в редакторе или загрузи свой файл. Черновик сохранится в этом браузере.
  3. Выбери C++ или Python и нажми «Проверить решение». Первый запуск загружает компилятор в браузер.
  4. Автопроверка использует примеры из условий и дополнительные тренировочные тесты. Для задач с открытыми тестами можно проверить готовый ответ.
  5. Запуск идёт на твоём устройстве. Лимит времени тренировочный и учитывает размер входа.
